# 第二版交付物设计验收记录

日期：2026-05-21

## 1. 当前结论

当前第二版交付物设计稿先冻结为“假数据验收版”。

这一版只用于确认销售展示网页和 Excel 结构，不代表酒店真实采集已经完成。

后续真实采集不再直接跑完整全量流程，必须回到阶段化验证：

1. 在途商旅单平台验证。
2. 航班四平台真实验证。
3. 青猫酒店候选池验证。
4. 酒店多口径四平台闭环。
5. 酒店扩展到 40 家。
6. 最后再做完整真实采集验收。

## 2. 离线网页包冻结口径

离线网页包继续作为第二版主销售展示材料。

当前冻结点：

- 首页同时展示航班价格和酒店价格入口。
- 首页配图使用真实飞机、真实酒店照片风格，不再使用纯动画插画。
- 航班入口和酒店入口左右视觉保持平衡。
- 航班价格条使用基数放大算法，价格接近时也能看出差异。
- 航班详情页保留“对比口径”视觉区，不再重复堆规则文字。
- 酒店页按集团 tab 展示。
- 酒店支持 4 个口径切换，页面默认展示每家酒店当前最完整、最可比的推荐口径；同完整度时按 `大床有早餐 > 大床无早餐 > 双床有早餐 > 双床无早餐` 选择。
- 酒店主对比结果放在详情页标题区右上方，金额放大，结论文案放在金额下方。
- 前台页面不出现采集按钮、调试信息、假数据、模拟数据等客户不该看到的字样。
- 销售离线包保持轻量，不打包全量网页截图证据目录；截图证据留在采集结果目录，内部复核时按需调取。

## 3. Excel 冻结口径

Excel 从临时客户简版恢复为第二版验收结构。

当前冻结 sheet：

1. 总览页
2. 航班汇总页
3. 酒店汇总页
4. 酒店集团明细页
5. 航班网页截图索引页
6. 酒店网页截图索引页
7. 内部留痕页
8. 失败记录页

Excel 固定规则：

- 不内嵌网页截图图片。
- 销售离线包不打包全量截图证据目录；截图证据保存在采集结果目录内。
- Excel 只保留证据编号、相对路径、来源页面和说明。
- 酒店明细必须保留平台原始房型名、归一口径、推荐口径标记、缺失原因。
- 酒店汇总页只展示至少 1 个口径四平台完整的酒店；4 个口径都不完整的酒店只进入后台留痕和失败记录。
- 失败记录页必须保留批次失败、平台缺失、口径缺失、候选放弃原因。
- 青猫差额公式统一按第二版新口径：
  - 青猫永远对比另外 3 家平台最低价。
  - 青猫差额 = 青猫价格 - 竞品最低价。
