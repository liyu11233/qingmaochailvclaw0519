# 第二版阶段3酒店候选池验证记录

记录时间：2026-05-21

## 验证目标

- 验证青猫差旅酒店入口能否作为酒店候选池来源。
- 先做单城市、单品牌、单晚小样，不进入四平台酒店比价。
- 当前验证口径：广州，如家商旅，2026-05-22 入住，2026-05-23 离店，1 间夜。

## 本次实现

- 新增青猫酒店候选池探测接口：
  - `GET /api/pilot/qingmao-hotel-candidates/status`
  - `POST /api/pilot/qingmao-hotel-candidates/run`
- 新增青猫酒店候选池解析：
  - 读取酒店总数，例如 `(共9家酒店)`。
  - 解析酒店名称、档次、评分、区域、地址、起价。
  - 过滤筛选项，避免把“五星 / 四星”等筛选标签误识别为酒店。
- 修复酒店日期选择：
  - 按第二版规则选择“明天入住、住 1 晚”。
  - 日期区间改为分步点击，避免 Element Plus 日期组件把旧入住日误保留为开始日期。
- 保存青猫酒店候选池证据截图：
  - `outputs/current/pilot/青猫差旅-酒店候选池.png`

## 当前结论

- 青猫差旅酒店入口可以作为酒店候选池来源。
- 单城市、单品牌、单晚候选池读取已跑通。
- 当前只验证到“候选酒店列表”，还没有进入携程商旅、阿里商旅、在途商旅同酒店匹配。
- 下一步应做酒店主口径闭环：随机选 1 家青猫候选酒店，读取青猫大床双早，再在其他 3 平台匹配同酒店、同日期、同主口径。
